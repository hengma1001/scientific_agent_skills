# scientific_agent_skills

A repository of reusable agent skills for scientific research workflows.

This package contains modular, task-oriented capabilities that help autonomous agents perform research-related work such as literature review, hypothesis generation, experiment planning, data analysis, and scientific writing support.

## What this repo provides

- Literature discovery and summarization support
- Research question framing and problem decomposition
- Experimental design and protocol planning
- Data extraction and structured analysis workflows
- Citation-aware note-taking and synthesis
- Scientific writing assistance for reports, papers, and summaries
- Integration-friendly skill definitions for agent orchestration systems

## Typical use cases

- Build research copilots that search, read, and summarize scientific papers
- Create agents that help generate research hypotheses from prior work
- Support planning for experiments, benchmarks, and validation studies
- Assist with structured analysis of results and evidence synthesis
- Prepare manuscript drafts, abstracts, and related materials

## Repository structure

This repository is designed to be extended with additional skill modules and tool integrations. Each skill can be implemented as a focused unit with clear inputs, outputs, and evaluation criteria.

## Design goals

- Reusable across different scientific domains
- Compatible with agent frameworks and workflow engines
- Emphasizes evidence-based reasoning and traceability
- Encourages structured outputs suitable for human review
- Easy to extend with domain-specific skills and datasets

## Example workflow

1. Define the research goal or question.
2. Retrieve relevant literature and relevant evidence.
3. Extract key claims, methods, and findings.
4. Synthesize a summary or research plan.
5. Validate assumptions and generate actionable next steps.

## Getting started

Add this repository to your agent environment and compose the available skills into research workflows that match your project needs. Customize prompts, tool connections, and evaluation checks to suit your scientific domain.
